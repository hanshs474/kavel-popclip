# Kavel for PopClip

A [PopClip](https://www.popclip.app/) extension: select text, click **Kavel**, get an AI image of it.
Source for the extension is in `Kavel.popclipext/`. See its readme for what is sent and how the
free tier works. Images come from [Kavel](https://www.kavel.ai/?utm_source=github&utm_medium=popclip).
