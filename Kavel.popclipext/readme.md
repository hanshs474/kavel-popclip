# Kavel

Select any text, click **Kavel**, and the text becomes an AI image that opens in your browser,
usually within a minute or two.

## What it sends

The selected text is sent to the [Kavel](https://www.kavel.ai/image?utm_source=popclip&utm_medium=extension)
image API as the prompt. Nothing else is sent.

## Free tier or your account

With no settings it uses Kavel's free tier: images are watermarked and there are only a couple a
day. Add an API key from [kavel.ai/settings/apikeys](https://www.kavel.ai/settings/apikeys?utm_source=popclip&utm_medium=extension)
in the extension's settings to run on your own account.
